# BD2有缘之客互动图鉴 · KindredAtlas

《棕色尘埃 II》「有缘之客」的手动操作指南。选择角色和服装，即可查看当前阶段的互动部位、操作方式、连续组合、进度条条件和阶段路线。**不需要安装 KT 或其他插件。**

## 怎么看

1. 在游戏中进入对应服装的「有缘之客」，可打开右上角提示模式。
2. 在图鉴左侧选择角色和服装，再选择与游戏当前姿态对应的阶段。
3. 先看泳道图，再点击其中的动作卡片，查看具体位置与短按、长按或拖拽说明。
4. 连续组合按顺序完成；阶段变化前先确认当前想看的动作已完成。

后续阶段默认折叠，可以主动展开。网址保留角色与阶段，点击「分享当前路线」即可分享；也可以打印正在查看的阶段。网页上的切换只用于浏览攻略，不会操作游戏。

## 这个图鉴提供什么

- 按角色、服装和阶段整理的泳道图。
- 面向手动操作的位置参照、触控方式与必要条件。
- 隐藏接续、固定顺序、进度解锁和攻略接续的完整步骤，以及单向／可逆阶段说明。
- 手机和电脑页面、角色搜索、阶段分享、打印和键盘操作。
- 清楚区分已确认说明与待核对内容；不编造未知拖拽落点、时长或动作顺序。

组合区同时显示当前阶段和整套服装的数量，其他阶段的组合可以主动跳转查看。进度解锁路线会说明准备动作、等待时间和目标区间；存在自然变化时以实时进度为准。

资料整理与实际操作可能存在差异，请以游戏当前提示为准。未核对内容会在对应条目标明，详情见[收录说明](DATA_NOTES.md)。图鉴不提供账号登录、付款、游戏下载或自动操作功能。

## 发布与维护

这是一个免费公开的纯静态网站，使用 GitHub Pages，无需服务器、账号或数据库，也不加载远端脚本与统计追踪。

入口为 `index.html`，页面样式和逻辑分别位于 `styles.css`、`app.js`；角色资料集中在 `data/characters.json`，更换资料不需要重写界面。网站可以部署到 GitHub Pages 的仓库根目录，也支持项目路径。

本地预览请使用普通静态 HTTP 服务器，避免浏览器对 `file://` 的资料读取限制。例如在项目目录运行 `python -m http.server 8000`，然后打开 `http://localhost:8000`。网站使用者在线浏览时不需要安装 Python 或其他环境。

本项目只包含手动指南、页面源码和原创品牌图标；不包含游戏原始图片、二进制、账号、登录状态或本机验证快照。
